{{- if .Values.zitadel.adminServiceKey.enabled }}

Administrative API access uses the declarative "admin-client" system user
(IAM_OWNER). ZITADEL trusts its public certificate; you authenticate against the
ZITADEL System API with the matching private key using a JWT profile.

Extract the private key for the admin-client:

  $ kubectl -n {{ .Release.Namespace }} get secret {{ include "zitadel.adminServiceKeySecretName" . }} -o jsonpath='{.data.tls\.key}' | base64 -d

The public certificate ZITADEL trusts is the "tls.crt" key in the same secret.
No Secret is created at runtime, so this works cleanly with GitOps tooling such
as ArgoCD.
{{- end }}
